# Generated OpenAPI models

This package contains request and response models generated from `contracts/http/openapi.yaml`.

## Boundaries

- Generated types are transport-only and must not appear in usecase, domain, or repository APIs.
- Files generated by oapi-codegen are committed so builds do not generate code implicitly.
- Generated files are never edited by hand.

## Regenerating

- Change the OpenAPI contract first.
- Run `make openapi-generate`, then review the generated diff and adapt handlers and tests.
